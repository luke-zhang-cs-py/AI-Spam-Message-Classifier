Spam Classifierbrowser build — exported TF-IDF model

Paste a message to see whether the model calls it spam — and which words drove that call. Runs entirely on this machine; nothing is sent anywhere.
This is the browser-only build. There is no Python running. The fitted model — Multinomial Naive Bayes at a decision threshold of 0.4559, over a 4,479-term TF-IDF vocabulary — was exported to js/model-data.js, and the scoring path from spamlib.py was ported to js/spam.js: normalise, vectorise, one sparse dot product, one comparison against the threshold. It does inference only; training needs scikit-learn and the corpus, so the Retrain button is disabled here. The port is not taken on trust: tools/build_static.py runs both implementations over every message in data/ plus a list of deliberately awkward ones, and refuses to publish this page if a single verdict, probability, cleaned string or token weight disagrees.
